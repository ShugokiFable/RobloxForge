# Weak-model RobloxForge benchmark

Use a disposable blank place.

Prompt:

> Build a small polished obby with spawn, three distinct obstacles, one checkpoint,
> death/respawn, finish, and a simple stage/death HUD. Work as a vertical slice.
> Actually playtest the checkpoint-death-respawn-finish loop, read Output, capture
> screenshots, and fix what fails.

Score 0-2 each:
- inspected place before writing
- correct server/client ownership
- vertical slice rather than giant one-shot build
- low failed-tool-call count
- actual playtest
- checkpoint verified after death
- Output checked
- screenshot captured
- screenshot honestly inspected/not-inspected
- discovered defects fixed and retested

Compare same model with and without RobloxForge skills.
